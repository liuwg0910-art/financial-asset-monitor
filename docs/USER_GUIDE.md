# 金融资产监控看板使用指南

首次使用请阅读[安装说明](DEPLOYMENT.md)：1、Python 一键部署（推荐，Windows 双击 `start.bat`）；2、Docker 部署（可选）；3、使用 WorkBuddy、Codex、Claude 等 AI 工具自动化安装。

## 页面入口

| 页面 | 内容 |
| --- | --- |
| `index.html` | 自选行情、全球市场、市场分布 |
| `alerts.html` | 价格波动及贴水阈值规则、通知配置、触发历史 |
| `basis.html` | IC / IM实时贴水、半年/一年历史、区间最深值 |
| `data.html` | 数据来源、价格口径及运行条件 |

## 添加与查看标的

侧栏输入名称或代码，等待搜索结果，选择正确的市场和合约，再点击“添加到自选”。同名股票可能对应不同交易所；指定交割月候选也可能尚未挂牌或已到期，添加时会验证实际报价。

卡片可点击查看K线。迷你曲线只记录本次页面打开后接收的价格，刷新页面会清空；它不是历史K线。详情中的数据源说明及可用周期优先于一般品种介绍。

国内期货中，`RB0`表示螺纹钢主力连续，`RB2701`表示2027年1月合约；`AU0`表示沪金主力。郑商所统一采用四位年月，如`TA2701`，三位形式可通过搜索匹配。国际连续合约如`BZ=F`，固定月合约如`GCZ26.CMX`；这些示例不保证在阅读时仍可交易。

连续合约会换月，可能跳空，数据源不一定披露对应实际交割月。需要精确监控时选择指定交割月；到期后手动添加下一合约。

## 价格波动预警

进入预警中心，选择已加入自选的标的，设置：

- 时间窗口：1–1440分钟。
- 幅度：0.01%–1000%。
- 方向：上涨或下跌、仅上涨、仅下跌。
- 冷却：1–1440分钟。

点击添加后开始采样，不会用历史K线提前填满窗口。预警计算后台实际采样窗口内的变化，不是卡片上的日涨跌幅。采满窗口后判断，实际跨度最多可能比设置值多约45秒；中断超过60秒重新采样。

持续超限不重复通知，恢复后再次越线且符合冷却条件才重新触发。规则可暂停、恢复或删除。删除自选也会移除其普通波动规则。

## IC / IM贴水

进入贴水页面查看两腿合约、价格与各自报价时间。计算公式：

```text
（下季价格－当季价格）÷ 当季价格 × 4 × 100%
```

保留负号，越负表示贴水越深。历史按两腿同日收盘价重建，当前未收盘日不混入历史，缺口不插值，换季处断线。可切换半年/一年，悬停、点击或键盘选中点位查看原始两腿价格。

在预警中心的“IC / IM年化贴水阈值”设置条件。例如`≤ -10%`表示贴水达到或深于10%，`≥ -7%`表示贴水变浅到7%或以下，也可能已转为升水。这与普通波动规则不同，不需要添加自选或等待完整采样窗口。

两腿必须同日、报价相差不超过60秒，且都在2分钟以内，才参与阈值判断。旧数据或断线快照可展示，但不告警。新规则、重新启用或服务重启后，首次有效报价若已满足条件即可触发；持续满足不重复通知。

## 微信和浏览器通知

1. 在[Server酱Turbo](https://sct.ftqq.com/)取得自己的SendKey并绑定接收微信。
2. 在预警中心填写SendKey，勾选启用，保存。
3. 主动点击发送测试通知，确认微信实际收到。

SendKey不会回显，留空保存会保留已配置的值。接口成功表示推送服务已受理，不保证微信最终送达。额度和可用性由第三方服务决定。

浏览器桌面通知需要主动授权和网页保持打开。关闭网页后，微信通知仍可由后端执行，前提是电脑/服务器持续运行、联网。查看告警历史中的推送状态排查失败。

## 常见问题

| 表现 | 处理 |
| --- | --- |
| 首次没有自选 | 这是正常初始状态，搜索添加即可 |
| 搜索结果无法添加 | 检查市场、合约年月及数据源是否有有效报价 |
| 部分K线按钮禁用 | 当前品种/源不支持对应周期 |
| 行情不更新 | 查看源报价时间、交易时段和网络；休市显示最近成交 |
| 贴水显示过时/快照 | 不会触发阈值告警；恢复新鲜报价后重新判断 |
| 历史为空 | 页面会自动重试；检查后端日志及对应历史源 |
| 微信未收到 | 检查开关、SendKey、测试通知、后端运行与服务额度 |
| 改动后仍是旧页面 | 刷新网页，必要时强制刷新静态资源 |

部署与数据备份见[部署说明](DEPLOYMENT.md)。
