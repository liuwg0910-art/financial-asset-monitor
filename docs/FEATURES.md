# 功能与数据说明

## 市场和数据源

| 类别 | 报价来源 | 历史来源 / 说明 |
| --- | --- | --- |
| A股、港股、美股 | 新浪财经 | Yahoo Finance |
| 恒生、国企指数 | 新浪财经 | Yahoo Finance |
| 恒生科技 | 新浪财经 | 腾讯财经，当前仅日线，量栏为成交额 |
| 黄金/白银别名 | 新浪财经 | COMEX连续期货，不代表现货历史 |
| 加密货币 | Binance公共行情 | Binance真实K线，涨跌采用24小时口径 |
| 国际商品期货 | Yahoo Finance | 同一合约代码的真实历史 |
| 国内期货 | 新浪财经 | 同一合约代码的真实历史 |
| 全球市场 | Yahoo Finance | 独立基准看板 |

国内涵盖上期所、能源中心、大商所、郑商所、广期所和中金所45个常用品种，具体映射见`backend/domestic_futures.py`。国际商品映射见`backend/futures.py`。这是代码中的支持清单，不等于所有候选月份均已挂牌。

股票通常相对前收盘价计算涨跌，国内期货相对昨结算价，Binance采用过去24小时变化。跨市场价格和不同单位不宜直接比较。

## 周期与历史

| 品类 | 周期 |
| --- | --- |
| 常见股票、恒生/国企、国际期货、贵金属历史 | 1分、5分、15分、1小时、4小时、日线，受源覆盖限制 |
| 加密货币 | 1分、5分、15分、1小时、4小时、日线 |
| 国内期货 | 1分、5分、15分、1小时、日线 |
| 恒生科技 | 日线 |

Yahoo的4小时线按UTC四小时窗口聚合真实小时数据；国内期货不拼接4小时线，避免跨午休或夜盘制造错误含义。异常OHLC被过滤，按时间去重排序；不补造缺失数据，不做本地复权，最后一根可能尚未收盘。

## 更新与恢复

- 自选报价约15秒共享缓存，前端轮询与WebSocket配合更新。
- 全球市场约60秒更新，单项失败可保留旧报价并标明。
- 贴水实时正常缓存30秒；失败或回退结果只短暂缓存，页面正常约30秒轮询。
- 完整贴水历史缓存1小时；失败、空结果或回退快照15秒后自动重试。
- 贴水实时、贴水历史与普通行情使用独立连接池，减少批量请求挤占。
- 最近有效贴水快照持久化；回退数据标为过时，不参与实时阈值告警。

## 季月配对

季月为3、6、9、12月。一般取最近未到期季月与下一季，第三个周五收盘后切换；法定假日顺延。已到期合约可从真实历史末日识别，未来日期暂按第三个周五估算，临近到期应核对交易所公告。

按当日配对合约的同日收盘价重建历史，不拿今天的固定合约对回算全年，也不把截图抽样点混入曲线。指标固定三个月年化，不按剩余天数调整，不扣交易成本。

## 存储与运行限制

JSON保存自选、规则、告警历史、微信凭证与贴水快照。通知队列、价格采样和部分缓存位于内存中。重启后普通波动规则重新采样；贴水规则在新鲜报价满足条件时可首次触发。

当前不支持账户认证、多用户隔离、多进程同时写JSON、交易执行和保证送达的消息队列。公开网页接口不构成交易所实时数据授权，外部服务可能变更或限流。
